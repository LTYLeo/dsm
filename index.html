Historical Project: This is a historical project experience website. Talkative DSM is an early symbolic AI project developed by TAI Research during elementary school years.

Function Introduction

This is an intelligent chatbot. You can chat with it and it has functions like calculator, number guessing game, timer, etc.

How to Use

You can input in English. For example, if you want to open the calculator, you can type "calculator". In the calculator function, you can input "addition" or "subtraction", or press number keys "1, 2, 3...".

Available Commands

  • "calculator" or "1" - Open calculator
  • "game" or "2" - Start number guessing game
  • "timer" or "3" - Set timer
  • "help" - Show this help
  • "time" - Show current time
  • "quit" or "exit" - Close the application
